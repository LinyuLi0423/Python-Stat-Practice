# Python-Stat-Practice
> First-year Mathematics & Statistics undergraduate practice repository | University of Warwick

This repository stores my self-practice code for statistics, linear algebra, numerical computation and introductory machine learning.
The exercises are built to consolidate mathematical foundation and prepare for US AI postgraduate application.

## 📚 Topics
- Probability & statistical simulation
- Linear algebra numerical calculation
- NumPy, Pandas & Matplotlib visualization
- Basic machine learning algorithm implementation

## 📁 File Structure
- `/linear_algebra` — Linear algebra coding exercises（matrix multiplication）
- `/prob_stats` — Probability and statistics simulation（dice‑rolling Monte‑Carlo）
- `/ml_basics` — Introductory machine learning practice（to‑be‑added）
